# fanpage-printer-limited

Fanpage Printers Limited Website
A professional website for Fanpage Printers Limited - offering comprehensive printing, graphic design, IT services, and cyber cafe solutions in Kericho, Kenya.

🌟 Features
Core Services
Printing Services: High-quality business cards, posters, brochures, and large format printing

Graphic Design: Logo design, branding, social media graphics, and marketing materials

IT Services: Windows/Linux installation, computer repair, network setup, and tech support

Cyber Cafe: High-speed internet access, computer rentals, and workspace

Web Design: Responsive website development and design

Government Services: Assistance with eCitizen, KRA, HELB, and other online services

Website Features
Responsive Design: Works perfectly on all devices (desktop, tablet, mobile)

Modern UI/UX: Clean, professional design with smooth animations

Contact Form: Integrated with FormSubmit for reliable form handling

Interactive Gallery: Filterable portfolio showcasing all services

Team Section: Meet the professional team behind the services

Fast Loading: Optimized for performance and speed

🛠️ Technologies Used
Frontend: HTML5, CSS3, JavaScript (ES6+)

Icons: Font Awesome 6.5.0

Fonts: Google Fonts (Inter)

Form Handling: FormSubmit.co

Lightbox: Custom JavaScript implementation

Responsive: CSS Grid & Flexbox

🚀 Installation & Setup
Prerequisites
Web browser (Chrome, Firefox, Safari, Edge)

Text editor (VS Code, Sublime Text, etc.)

Local server (for testing)

Local Development
Clone or download the project files

Open index.html in your browser, or

Set up a local server:

bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8000
Deployment
Upload all files to your web hosting service

Ensure file paths are correct for your server structure

Test all functionality including forms and links

Update contact information in all HTML files

📧 Contact Form Setup
The contact form uses FormSubmit for reliable email delivery:

Configuration
Form action: action="https://formsubmit.co/your-email@gmail.com"

Update email: Replace kiruigideon2006@gmail.com with your actual email

Customize settings:

_subject: Email subject line

_template: Email template style

_next: Success page redirect

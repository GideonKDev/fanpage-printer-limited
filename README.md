# Fanpage Printers Limited Website

This repository contains the official website for **Fanpage Printers
Limited**, a printing, graphic design, IT solutions, and cyber café
service provider based in Kericho, Kenya.

## Features

-   Fully responsive design\
-   Modern and clean UI/UX\
-   Contact form powered by FormSubmit\
-   Interactive gallery with filters\
-   Team section\
-   Optimized for fast loading and performance

## Services Offered

-   Printing (business cards, posters, brochures, large format)\
-   Graphic design (logos, branding, social media graphics)\
-   IT services (Windows/Linux installation, computer repair,
    networking)\
-   Cyber café services\
-   Web design\
-   Government services (eCitizen, KRA, HELB, etc.)

## Technologies Used

-   HTML5, CSS3, JavaScript\
-   Font Awesome 6.5.0\
-   Google Fonts (Inter)\
-   FormSubmit for email handling\
-   CSS Grid and Flexbox layout

## Running Locally

Open `index.html` directly in your browser, or start a local server:

### Python

    python -m http.server 8000

### Node.js

    npx http-server

### PHP

    php -S localhost:8000

## Deployment

-   Upload all files to your hosting provider\
-   Confirm all file paths are correct\
-   Test the contact form\
-   Update contact info where necessary

## Contact Form Setup

Update the form action to your email:

    action="https://formsubmit.co/your-email@gmail.com"

## Customization

-   Edit services in `services.html`\
-   Update gallery images in `gallery.html`\
-   Update team details in `contact.html`\
-   Modify colors in the CSS variables inside `new.css`
